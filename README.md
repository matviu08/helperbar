# HelperBar · сайт

Статична демонстраційна сторінка HelperBar для Windows. Українська мова, адаптивна верстка, живі очі, чотири інтерактивні стани острова та перемикання акцентного кольору.

## Гілки

- `main` — цей сайт.
- [`helperbar`](https://github.com/matviu08/helperbar/tree/helperbar) — вихідний код Windows-програми та її документація.

## Запуск локально

Встановлення залежностей і збірка не потрібні. Для локального сервера потрібен Node.js 18 або новіший:

```sh
npm run dev
```

Відкрий `http://127.0.0.1:4173/helperbar/`. Можна також відкрити `index.html` безпосередньо.

```sh
npm run check
```

Перевірка контролює посилання, локальні ресурси, унікальні ID та активні посилання на інсталятор потрібного випуску.

## GitHub Pages

У репозиторії відкрий **Settings → Pages → Build and deployment → Deploy from a branch**, вибери **main** і **/(root)**, збережи. Сайт не потребує токенів, сервера чи власного GitHub Actions workflow. `.nojekyll` вимикає обробку Jekyll; усі посилання на ресурси відносні й працюють у `/helperbar/`.

## Демонстрація

- Очі реагують на курсор і натискання.
- Мініплеєр показує анімацію без звуку; кнопку паузи можна натискати.
- Фокус — локальний демонстраційний таймер на 25 хвилин із паузою.
- Картка навушників використовує явно позначені прикладові дані.
- Акцентні кольори перемикаються в блоці персоналізації.
- Є керування анімаціями, підтримка `prefers-reduced-motion`, клавіатурної навігації та семантичних FAQ.

Сайт не звертається до пристроїв або медіасесій Windows, не містить аналітики, зовнішніх шрифтів чи сторонніх JavaScript-залежностей.

## Кнопка інсталятора

Обидві кнопки **«Завантажити інсталер»** — звичайні посилання, що працюють і без JavaScript. Вони завантажують `HelperBar-Setup-x64.exe` з [GitHub Release v0.13.1](https://github.com/matviu08/helperbar/releases/tag/v0.13.1). Файл має розмір приблизно 57 МБ, містить .NET Desktop Runtime й призначений для Windows 10 22H2 / 11 x64. Інсталятор поки не підписаний; це пояснено у FAQ. У випуску також доступний `SHA256SUMS.txt`.

Посилання прив'язане до конкретної версії, щоб напис на кнопці, вимоги та завантажений файл завжди відповідали одне одному. Для наступного випуску спочатку опублікуй перевірені EXE і SHA-256 у GitHub Releases із тегом коміту гілки `helperbar`, потім онови обидва посилання, версію, розмір і FAQ в `index.html` та очікуваний шлях у `tools/check.mjs`. Виконай `npm run check` і відправ зміни в `main` — GitHub Pages оновить сайт.

Інсталятор не зберігається у гілці сайту; GitHub Releases обслуговує його завантаження окремо. Сайт: [matviu08.github.io/helperbar](https://matviu08.github.io/helperbar/).
