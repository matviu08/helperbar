Це вже можна завантажити?+

Так. Кнопка завантажує інсталер HelperBar 0.13.1 для Windows x64 із GitHub Releases. Відкрий файл і пройди український майстер встановлення. Права адміністратора не потрібні. Опис випуску та контрольна сума доступні на GitHub.

Що потрібно для роботи?+

Windows 10 22H2 (збірка 19045) або новіша, зокрема Windows 11, із підтримкою x64. .NET Desktop Runtime уже включено в інсталер — окремо завантажувати його не потрібно. Для збірки з коду потрібен .NET SDK 10.

Чи має інсталер цифровий підпис?+

Поки ні. Windows може показати повідомлення про невідомого видавця. Завантажуй файл із кнопки на цьому сайті або з офіційного випуску HelperBar на GitHub, де також є SHA-256 для перевірки цілісності файлу.

Звідки острів знає, що грає?+

Програма використовує медіасесії Windows для назви, обкладинки та керування. YouTube і YouTube Music у браузері та Spotify уже перевірені. Анімація реагує на системний звук; мікрофон для цього не потрібен.

Чи покаже заряд моєї мишки?+

Якщо Windows отримує від пристрою заряд. Є підтримка Bluetooth; для USB-приймачів усе залежить від драйвера. Коли відсоток недоступний, острів чесно показує це — без вигаданих значень.

Демо керує моїм комп’ютером?+

Ні. Це статична демонстрація в браузері з ілюстративними даними. Вона не читає твою музику, не підключається до пристроїв і не змінює налаштування Windows.
